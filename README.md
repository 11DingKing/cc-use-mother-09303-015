# 产教需求版本库

本项目维护产教需求版本库的领域约定、角色边界、样例数据与后端实现，供后端服务、接口和自动化验证统一使用。当前契约覆盖合作企业、院校专业负责人、课程设计人员，并明确需求版本、双方确认、影响分析、替代链等关键约束。

## 业务背景

院校课程修订引用的企业岗位能力说明可能已失效多版，且无人能说明当时采用理由。本系统将企业需求连同**证据来源、适用地区、有效期、发布方**保存为不可变版本，关联课程、实训项目与技能标准；发布需企业与院校共同确认；撤回或更正只产生替代链，既有培养方案始终引用原版本；影响分析列出未来调整范围。

## 目录

- `domain/contract.json`：领域角色、状态、约束和样例。
- `src/domain_contract/`：契约读取与确定性校验。
- `src/demand_repo/`：后端实现（零第三方依赖，仅需 Python 3.11+）
  - `models.py`：领域模型（需求版本、证据、双方确认、版本节点与有向关联、事件）。
  - `store.py`：SQLite 持久化（WAL、单写锁、追加式事件日志、唯一约束兜底）。
  - `repository.py`：全部业务规则与影响分析。
  - `http_api.py` / `__main__.py`：标准库 HTTP 服务。
- `tools/check_contract.py`：命令行摘要检查。
- `tests/`：契约回归、领域不变量（含并发）与 HTTP 端到端测试。

## 状态机（与契约一致）

```
采集 ──提交──▶ 核验 ──双方确认齐备──▶ 发布 ──被引用──▶ 关联
                 │                     │
                 └──驳回──▶ 采集(驳回态可修订)   └──被后继替代──▶ 替代
```

更正 / 撤回 / 失效后恢复都从当前生效版本派生新的草稿版本，经同一核验与双方确认流程发布；旧版本转为“替代”态并原样保留。

## 关键不变量

1. **需求版本不可变**：发布后的内容、证据、有效期不可修改；任何变更产生新版本号。
2. **双方确认**：企业、院校两方确认齐备才能发布；同方确认幂等；驳回后确认清空。
3. **替代链线性、不分叉**：只能从最新生效版本发起替代（`UNIQUE(supersedes_id)` 与事务内族头检查双重保证）；撤回是墓碑版本，恢复时沿链回溯复制最近实质版本内容。
4. **引用钉版本**：课程/实训/标准的 `references` 指向具体版本，不随换版迁移；禁止引用未发布、已替代、已撤回或过有效期版本。
5. **循环关联拒绝**：新增关联前在活动有向图上做可达性检测，成环（含自环）即返回冲突。
6. **并发安全**：每个写操作为一个 `BEGIN IMMEDIATE` 串行事务，并发发布/并发更正只有一个成功，业务表与审计事件原子提交。
7. **历史可解释**：所有动作（采集理由、证据文号、确认、发布、更正/撤回/恢复理由、关联变更）写入追加事件表，可按版本族回答“当时为什么采用这份需求”。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/demands` | 采集需求（v1，采集态） |
| GET | `/demands/{id}` | 查询版本 |
| POST | `/demands/{id}/submit` `/reject` | 提交核验 / 驳回 |
| POST | `/demands/{id}/confirm` | 企业/院校确认（`party`: enterprise/college） |
| POST | `/demands/{id}/publish` | 双方齐备后发布 |
| POST | `/demands/{id}/correct` `/withdraw` `/restore` | 更正 / 撤回墓碑 / 失效后恢复 |
| GET | `/families/{family_id}` | 替代链（v1→…→当前） |
| POST | `/nodes` | 建课程/实训/标准/培养方案节点 |
| POST/DELETE | `/links` | 建立/解除关联（解除为追加墓碑，可重新激活） |
| GET | `/impact?family_id=&as_of=` | 影响分析：过期钉住版本、待调整节点、受影响培养方案 |
| GET | `/history?aggregate_id=` | 审计事件时间线 |

错误映射：400 校验失败，404 不存在，409 状态冲突/并发冲突/成环/链分叉。

## 验证

```bash
# 全部测试（契约 + 领域不变量 + 并发 + HTTP 端到端）
python3 -m unittest discover -s tests -v

# 编译检查
python3 -m compileall -q src tools tests

# 契约摘要
python3 tools/check_contract.py domain/contract.json

# 启动服务（PYTHONPATH=src；可选 db 路径、host、port）
PYTHONPATH=src python3 -m demand_repo repo.db 127.0.0.1 8080
```
